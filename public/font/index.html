Замечания

    Шрифты взяты из исходников Bonzar/wedding: самохостируемые лежат рядом с этой страницей, Canva-шрифты берутся из бандла макета design06-exact. Паспорт прочитан из таблиц name, head, hhea и OS/2 самих файлов; сетки символов построены по cmap, поэтому показывают только те знаки, которые в шрифте действительно есть. Раздел «Где стоит в приглашении» сверен с реальным рендером: собранный сайт открыт в Chromium, и для каждого текстового элемента через DevTools-протокол получен платформенный шрифт, которым он нарисован.
